# WebAsk skills

A skill is a folder with a `SKILL.md` file: plain-language instructions telling the assistant how to solve a
task with WebAsk MCP tools. The assistant picks a skill up on its own when your request fits, so there's no
need to name it.

Skills contain no code and run nothing. All a skill needs is access to WebAsk, which the
[MCP server](../README.md#quick-start) provides.

## Installing

**Claude Code: as a plugin.** Installs all skills and the MCP server at once and asks for your key:

```text
/plugin marketplace add WebAskio/webask-mcp
/plugin install webask-en@webask
```

**Any assistant: one command.** [skills](https://skills.sh) finds your installed agents and asks where to
put the skills:

```bash
npx skills add https://github.com/WebAskio/webask-mcp/tree/main/en/skills
```

**Any assistant: from an archive.** Download a skill's ZIP from the table above, or all of them at once:
[webask-skills-en.zip](https://github.com/WebAskio/webask-mcp/releases/download/skills-latest/webask-skills-en.zip). Unzip into the folder your assistant reads skills
from and restart it:

| Assistant | Folder in your project |
|---|---|
| Claude Code | `.claude/skills/` |
| Codex, Cursor | `.agents/skills/` |
| Gemini CLI | `.gemini/skills/` |

You should end up with:

```text
your-project/
└── .claude/
    └── skills/
        └── webask-quiz-from-brief/
            ├── SKILL.md
            └── references/
```

## What's inside a skill folder

| File | Why |
|---|---|
| `SKILL.md` | the skill itself: when to use it, ordered steps, what not to do |
| `references/` | reference files the skill loads on demand |
| `agents/openai.yaml` | the MCP tools the skill depends on |
| `README.md` | description for GitHub; the assistant doesn't need it |

## Versions

A skill's version is in its `README.md`, the history is in [CHANGELOG.md](../../CHANGELOG.md).

- **Patch** — wording fixes. No need to download again.
- **Minor** — a new step, rule or reference. Worth updating.
- **Major** — the skill was rewritten. Better delete the old copy.
