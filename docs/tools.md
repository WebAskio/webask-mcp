# Инструменты WebAsk MCP

На сервере 161 инструмент. 57 только читают данные, 24 — необратимые, сервер помечает их аннотацией `destructiveHint`. Остальные меняют данные, но без потерь: переименовать, настроить, включить.

Точный список клиент получает запросом `tools/list` при подключении — он всегда свежее этой страницы. Подробные параметры и примеры ответов — в [документации MCP-сервера](https://webask.io/dev/api/mcp).
