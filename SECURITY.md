# Безопасность

## Как сообщить о проблеме

Нашли уязвимость в MCP-сервере WebAsk или в навыках из этого репозитория — напишите в
[поддержку](https://webask.io/support). Пожалуйста, не публикуйте детали в issues, пока проблема не
устранена: такие обращения мы разбираем в первую очередь.

## Как устроен доступ

К MCP-серверу подключаются по API-ключу из кабинета WebAsk (**Настройки → API / MCP**). Ключ действует с
правами владельца ключа, а инструменты записи проверяют то же, что и интерфейс конструктора: роль участника
и тариф пространства. Ключ отзывается в любой момент там же, где создаётся.

## Секреты в репозитории

Секретов здесь нет и быть не должно. В конфигах из `clients/` вместо ключа стоит `YOUR_API_KEY`, плагин
Claude Code спрашивает ключ при установке и хранит его в системном хранилище паролей.

Заметили в репозитории что-то похожее на настоящий ключ или персональные данные — сообщите в поддержку.
