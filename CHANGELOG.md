# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/). Версии отдельных навыков — в их
`README.md`.

## [2026-09-30]

### Добавлено
- Установка в один клик для VS Code и Cursor, расширение для Gemini CLI (сервер и навыки, ключ
  спрашивается при установке), установка навыков в любой ассистент командой `npx skills add`.
- Публикация в официальном реестре MCP (`io.github.WebAskio/webask-mcp`).

## [2026-09-29]

### Добавлено
- Первая публикация: подключение к MCP-серверу `https://mcp.webask.io/mcp/v1`, готовые конфиги для Claude Desktop,
  Cursor, VS Code, Codex и Gemini CLI, справочник 161 инструмент.
- 25 навыков на русском и английском — те же, что на витрине [webask.io/skills](https://webask.io/skills).
- Плагин для Claude Code: MCP-сервер и навыки одной установкой, ключ спрашивается при установке.
- Сборка ZIP-архивов английских навыков в релиз `skills-latest`.
